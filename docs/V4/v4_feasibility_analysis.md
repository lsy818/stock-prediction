# V4 优化方案可行性与设想深度剖析

你在 `V4.md` 中提出的设想非常专业，且直击了前三个版本在“数据噪音”、“模型过拟合”和“实盘交易摩擦”上的三大痛点。以下是我对这 7 个维度的可行性分析与深入讨论：

## 1. 数据池：沪深300 + 中证500 (约800只)
* **可行性**：⭐⭐⭐⭐⭐ (极高)
* **分析**：这是一个**极其完美**的折中方案。V2 证明了沪深300太少（容易无票可买或信号稀疏），V3 证明了全市场太杂（微盘股的涨跌停、高波动会造成严重的“幸存者偏差”和资金绞肉机）。中证800（300+500）剔除了流动性极差的尾部股票，同时保证了充足的模型训练样本（800只 * 2500天 = 200万条样本）。
* **技术细节**：读取 `000905.csv` 时，深市股票代码前导 0 丢失的问题，只需在 pandas 中使用 `str.zfill(6)` 即可轻松修复。

## 2. 模型选择：回归 GRU 体系
* **可行性**：⭐⭐⭐⭐ (高)
* **分析**：
  * **Transformer 的退役**：Transformer 在序列很长、维度很高时确实很强，但对于信噪比极低的金融日频数据，它往往会去“死记硬背”微盘股的极端噪音。
  * **GRU + 轻量 Attention (推荐)**：给 GRU 加上针对最近 5-20 天的 Local Attention 是绝佳的思路。因为对于股票来说，昨天的异动比 20 天前的异动重要得多。
  * **3个 GRU 集成 (Ensemble)**：非常可行！由于深度学习在金融数据上极其容易陷入局部最优，使用 3 个不同随机种子或不同隐藏层大小的 GRU 输出后取平均，能**大幅降低回撤方差**。

## 3 & 5. 特征优化与市值风格特征
* **可行性**：⭐⭐⭐⭐ (高)
* **分析**：
  * **贝叶斯优化 (Optuna)**：可以用来自动搜索超参数（如 lr, hidden_size）甚至特征子集。但如果用来搜特征权重，由于特征太多（59个），搜索空间太大，效率很低。
  * **更聪明的做法**：在进入 GRU 之前，我们可以用 LightGBM 先跑一遍特征重要性，剔除掉纯噪音特征，然后把剩下的 20-30 个核心特征喂给模型。
  * **添加市值特征 (Market Cap Style)**：**必加项！** 沪深300和中证500的博弈逻辑完全不同，模型必须知道它当前预测的是大盘股还是中盘股。可以把 `流通市值(circ_mv)` 取对数（log）后作为一个强特征，或者直接做一个 One-hot 编码（0代表沪深300，1代表中证500）。

## 4. 记忆窗口 (Seq_len) 与时间切分
* **可行性**：⭐⭐⭐⭐⭐ (极高)
* **分析**：目前的 `seq_len = 30` 可能太长了。A 股的短期动量记忆通常只有 1-2 周。建议在 V4 中把 `seq_len` 缩短为 `10` 或 `15`。不仅能加速训练，还能强迫模型只关注最近的量价堆积。

## 6. 核心争议：预测 [Low, High] 区间与挂单策略
* **可行性**：⭐⭐ (存在较大实盘落地风险)
* **分析**：
  * **理论愿景**：如果能预测高低点区间，并且在价格回落到区间下界时接盘，确实能大幅降低买入成本（吃日内超跌）。
  * **数学难度**：在金融中，预测“均值（Mean Return）”已经很难了，预测“极值（Tails/Range）”几乎是不可能完成的任务。极值受当天的随机恐慌/狂热情绪影响极大，噪音是均值的十倍以上。
  * **实盘硬伤（挂单无法成交）**：假设你预测明天最低价是 10.0，你挂单 10.0 买入。如果明天真的跌到了 10.0，往往只是一笔瞬间砸盘，交易所是“价格优先、时间优先”，你的单子排在后面根本**无法成交**。而如果它跌穿了 10.0（比如跌到 9.5），你的挂单成交了，但你买在了半山腰。这就是著名的**“限价单逆向选择（Limit Order Adverse Selection）”**。
  * **V4 妥协建议（VWAP 执行）**：我们依然预测“次日收益率”，但在回测引擎中，把买入/卖出价格从**“开盘价”**改为**“次日 VWAP (成交量加权平均价)”**。VWAP 代表全天平均成本，算法交易（TWAP/VWAP 机器人）在实盘中是非常容易精准执行到这个价格的，既避免了开盘的剧烈波动，又极其贴近真实落地。

## 7. 持仓比例（大盘择时过滤）
* **可行性**：⭐⭐⭐⭐⭐ (极高，V4 回撤控制的关键)
* **分析**：在 V3 的测试中，我们发现了强制满仓在熊市下杀时的毁灭性。
  * **加入宏观均线防线**：在回测引擎中加入大盘择时——例如，如果沪深300指数（或中证800指数）跌破了 60 日均线，系统强制将最大仓位限制在 30%，或者直接清仓休息。这就是量化常说的“指数过滤器”。

### 下一步建议
我建议 V4 版本的核心代码架构分为以下三个冲刺阶段：
1. **数据层**：重写 `dataset` 构建逻辑，融合 300+500 标的，并加入市值 Log 特征。
2. **模型层**：构建 `Attention-GRU Ensemble`（带本地注意力机制的多个 GRU 集成），将目标特征集精简，`seq_len` 改为 15。
3. **回测层**：引入大盘指数 MA60 择时过滤器，将执行价格从 Open 替换为 VWAP。
