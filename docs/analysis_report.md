### 1.2 数据特征分析

**量价数据特征：**
- 开盘价、最高价、最低价、收盘价具备日内价格路径信息
- `pre_close` 为除权昨收价，`pct_chg` 已基于除权价计算，可直接使用
- `vwap`（加权均价）反映当日平均成交成本
- 量价数据为高频使用、低缺失率的核心数据

**基本面指标特征：**
- PE/PE_TTM 在亏损时为空值（较多缺失）
- PB/PS 覆盖更全
- 换手率、量比反映市场参与热度
- 市值数据有助于区分大盘/小盘股风格

**资金流向特征：**
- 按成交金额分档（5万/20万/100万为界）统计主动买卖
- 净流入额 `net_mf_amount` 综合反映主力资金动向
- 大单/特大单数据更能反映机构行为

**关键挑战：**
1. **高噪声**：个股日收益率信噪比极低
2. **非平稳性**：市场风格、波动率时变
3. **截面相依**：同行业/板块股票走势高度相关
4. **缺失值**：新股上市时间不一致，部分指标有结构性缺失

## 三、标签构造

### 3.1 预测目标定义

预测 **T+1 日收益率**（基于收盘价）：

$$y_t = \frac{close_{t+1} - close_t}{close_t}$$

### 3.2 多周期可选方案

| 方案 | 标签 | 优点 | 缺点 |
|------|------|------|------|
| 回归（推荐） | T+N 日收益率 | 与IC计算天然一致，保留收益率幅度信息 | 极端值需要处理 |
| 二分类 | 涨/跌方向 | 简单直接 | 丢失幅度信息，小涨小跌难以区分 |
| 排序 | 截面收益率分位数 | 直接优化排序质量 | 计算复杂 |

**推荐方案：回归**，配合截面标准化后的收益率作为标签。

### 3.3 标签预处理

- 对原始收益率做 **截面去均值 + 截面标准化**（每交易日），消除市场beta影响
- 极端值截尾（±3σ以外替换为边界值），降低噪声干扰
- 去均值后的收益率称为 **alpha收益**：$y_t^{adj} = (y_t - \mu_t^{cross}) / \sigma_t^{cross}$

## 五、数据预处理与窗口构造

### 5.1 时间划分

```
训练集：2019-01-01 ~ 2024-12-31
验证集：2025-01-01 ~ 2025-12-31
测试集：2026-01-01 ~ 2026-05-15（比赛前最后数据）
（模拟交易比赛本身即为最终测试）
```

选择 2019 年起点的原因：
- 2019年之前新闻数据不可用（若使用）
- 2016-2018 年市场环境（熔断、股灾恢复期）与后续差异较大
- 5年训练数据 + 1年验证 + 最新数据测试，覆盖完整市场周期

### 5.2 滑动窗口构造

```
窗口长度 L = 60 个交易日
步长 = 1 个交易日
输入: X[t-L+1:t] = 最近60个交易日的特征序列 [L, F]
标签: y[t] = T+1日去均值收益率
```

对每个交易日的每只股票，取过去 60 天特征序列作为模型输入，预测次日收益率。

### 5.3 标准化方案（避免数据泄露）

**逐样本标准化（Per-sample Normalization）**：
- 对每个滑动窗口内的特征，**独立计算均值和标准差进行标准化**
- 不跨时间、不跨股票
- 消除不同股票量级差异，同时避免使用未来信息

```python
# 对每个 60 天窗口
X_window = (X_window - X_window.mean(axis=0)) / (X_window.std(axis=0) + 1e-8)
```

若某些特征需要截面标准化（如PE排名），**当天截面独立计算**，不使用未来日期数据。

### 5.4 标签截面标准化

标签在每交易日截面上做：
$$y^{final}_t = (y_t - \mu_t) / \sigma_t$$

使模型聚焦于**截面相对排序**而非绝对涨跌。

## 六、模型架构设计

### 6.1 总体思路

采用 **GRU + Multi-Head Attention** 的混合架构：
- **GRU**：高效捕捉时序依赖，参数量可控
- **Self-Attention**：增强对关键时间点的关注（如财报日、政策发布日）
- **残差连接 + LayerNorm**：稳定训练

### 6.2 模型结构

```
Input: [batch, 60, 47]  (# 60天窗口, 47维特征)

├── Input Projection: Linear(38 → 128) + BatchNorm
├── Position Encoding: Learned (60 positions, dim=128)
├── GRU Layer 1: GRU(128, hidden=256, bidirectional=True)
│   └── Output: [batch, 60, 512]
├── GRU Layer 2: GRU(256, hidden=128, bidirectional=True)
│   └── Output: [batch, 60, 256]
├── Multi-Head Attention: 4 heads, dim=256
│   └── Attend over time steps, weighted sum
├── Global Average Pooling + Global Max Pooling (concatenate)
├── MLP Head:
│   ├── Linear(512 → 256) + GELU + Dropout(0.3)
│   ├── Linear(256 → 128) + GELU + Dropout(0.3)
│   └── Linear(128 → 1)  # 输出预测分数
Output: [batch, 1]
```

### 6.3 设计理由

1. **GRU 优于 LSTM**：参数更少，在中等长度序列（60步）上效果相近
2. **双向GRU**：同时利用历史和未来上下文（在已知的60天窗口内是安全的）
3. **Attention**：让模型自适应关注窗口内关键时间点
4. **双池化**：Average捕获整体趋势，Max捕获极端信号
5. **较深MLP Head**：增加非线性表达能力

### 6.4 备选/对比模型

| 模型 | 用途 |
|------|------|
| **MLP**（展平60×38直接输入） | 简单基线对比 |
| **LSTM + Attention** | GRU对照 |
| **Transformer Encoder**（4层） | 纯注意力机制对照 |
| **Temporal CNN (TCN)** | 卷积时序对照 |

推荐主模型使用 GRU+Attention，训练 MLP 作为基线。

### 6.5 正则化策略

- Dropout(0.3) 在 MLP Head 和 GRU 层间
- 梯度裁剪 (max_norm=1.0)
- Early Stopping (验证集 IC 不提升 20 轮停止)
- 学习率 warmup + cosine 衰减

## 七、训练策略

### 7.1 损失函数

采用 **MSE + Ranking Loss** 组合：

```python
loss = mse_loss + 0.1 * ranking_loss
```

- **MSE Loss**：预测分数与截面标准化收益率的均方误差
- **Pairwise Ranking Loss**：每交易日随机采样股票对，若股票A收益率 > 股票B，则预测分应满足 score_A > score_B

Ranking Loss 公式（Margin Ranking Loss）：
$$\mathcal{L}_{rank} = \max(0, -(score_A - score_B) \cdot sign(y_A - y_B) + margin)$$

### 7.2 优化器配置

| 参数 | 值 |
|------|------|
| Optimizer | AdamW |
| Learning Rate | 1e-3（warmup 5 epochs to peak, cosine decay to 1e-6） |
| Weight Decay | 1e-4 |
| Batch Size | 2048 (每个样本为单股票60天窗口) |
| Epochs | 100 (early stopping patience=20) |

### 7.3 训练技巧

- **梯度累积**：若显存不足，batch_size 减小但累积4步
- **混合精度训练** (AMP)：加速训练、节省显存
- **采样策略**：每epoch随机打乱股票-日期对，但确保验证集按时间顺序

### 7.4 标签平滑

对收益率极端值做 Winsorize 处理（截尾1%和99%分位数），降低个别异常样本对训练的干扰。

## 八、评估指标

### 8.1 基础指标

**IC (Information Coefficient)**：
- Rank IC：每日预测分数与未来收益的截面 Spearman 相关系数
- 报告均值、标准差、正显著比例

**ICIR (IC Information Ratio)**：
$$ICIR = \frac{mean(IC_t)}{std(IC_t)}$$

ICIR > 0.5 通常认为模型有稳定预测能力。

**方向胜率**：预测分数正负与收益率正负一致的比例。

### 8.2 回测指标

基于交易策略在历史数据上模拟（详见下一节），计算：
- **年化收益率**：几何平均年化
- **夏普比率**：年化收益 / 年化波动（无风险利率取2%）
- **最大回撤**：净值曲线的最大回撤幅度
- **胜率**：盈利交易日占比
- **换手率**：日均调仓比例

与 **沪深300指数** 和 **等权持有策略** 对比。

## 九、交易策略设计

### 9.1 基础策略（作业推荐方案）

```
参数: n=20 (持仓数), k=2 (每日调仓数)

Day 0: 等权买入预测得分最高的 n 只股票
Day t (t>0):
  1. 卖出持仓中预测得分最低的 k 只
  2. 买入股票池中预测得分最高的 k 只
  3. 调仓后 n 只股票等权重（各 5% 仓位）
  
约束：
  - T+1 机制：当日买入次日才能卖出
  - 涨停不能买入、跌停不能卖出
  - 满仓操作
```

### 9.2 改进方向（可选）

1. **分数加权**：按预测分数分配仓位权重，而非等权
2. **动态n/k**：根据预测分数离散度（日内IC预期）动态调整
3. **止损止盈**：单只股票回撤超阈值时强制卖出
4. **行业中性**：控制行业暴露，避免集中在单一行业

初期实现推荐使用基础策略，确保回测框架正确后再尝试改进。

### 9.3 回测框架

自行编写或使用 `backtrader`/`zipline-reloaded` 等库。

关键模块：
1. 每日生成预测分数
2. 根据交易规则计算目标持仓
3. 考虑T+1、涨跌停等约束
4. 记录每日净值和持仓
5. 输出收益曲线和统计指标

## 十一、风险与注意事项

1. **数据泄露红线**：标准化必须在窗口内/截面内进行，严禁使用全量统计量
2. **存活偏差**：训练时应包含已退市股票的历史数据（数据已包含）
3. **交易成本**：回测建议考虑 0.1% 手续费 + 0.1% 滑点，比赛实盘也需注意
4. **过拟合**：金融数据信噪比低，模型容量不宜过大，需严格按时间划分验证
5. **计算资源**：全量训练数据量约 (5000股票 × 1500交易日) ≈ 750万个样本，需合理管理内存
