## 四、历史回测结果

**策略**：等权持有 20 只股票，每日卖出得分最低 2 只，买入得分最高 2 只，等权再平衡。
**约束**：T+1 交易、涨跌停限制、0.1% 手续费 + 0.1% 滑点，满仓操作。
**初始资金**：100 万元。

### 4.1 验证集回测（2025 年，183 个交易日）

| 指标 | 值 |
|------|------|
| **总收益率** | **+55.02%** |
| **年化收益率** | **+82.01%** |
| **夏普比率** | **3.16** |
| **最大回撤** | -9.07% |
| **胜率** | 60.11% |

### 4.2 测试集回测（2026 年 1-5 月，23 个交易日）

| 指标 | 值 |
|------|------|
| **总收益率** | **+1.72%** |
| **年化收益率** | +20.34% |
| **夏普比率** | 1.13 |
| **最大回撤** | -2.02% |
| **胜率** | 39.13% |

> 测试集样本仅 23 天，年化指标参考价值有限。实际总收益 +1.72% 为正，实现了扭亏为盈。

## 五、实验迭代对比

| 指标 | 第一轮 (T+1) | 第二轮 (T+3) | 提升 |
|------|-------------|-------------|------|
| Val Rank IC | 0.060 | **0.095** | +58% |
| Val 总收益 | +15.9% | **+55.0%** | 3.5x |
| Val 夏普 | 1.07 | **3.16** | 3.0x |
| Test 总收益 | -6.25% | **+1.72%** | 扭亏为盈 |
| Test 夏普 | -1.94 | **+1.13** | 转正 |

### 关键优化

1. **T+1 → T+3 预测目标**：多日收益信号更稳定，噪声更低
2. **Dropout 0.3 → 0.4 / WD 1e-4 → 3e-4**：强化正则化控制过拟合
3. **模型容量 444K → 253K**：更小模型，更好泛化
4. **训练采样 1/5 → 1/2**：2.5 倍训练数据
5. **回测引擎全面修复**：T+1 约束、首日建仓、等权再平衡、满仓操作

## 七、模拟交易指南

最新预测文件：`output/daily_predictions.csv`

每日操作流程：
1. 读取当日 `trade_date` 最新日期的预测数据
2. 按 `score` 降序排列，取前 20 只作为目标持仓
3. 对比当前持仓，卖出不在 top-20 的股票，买入新进入 top-20 的股票
4. 调仓数量控制在每日 2 只（k=2）
