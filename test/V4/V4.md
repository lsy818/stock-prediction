### 6. 交易策略再谈
* 当前策略：仅使用开盘价判断。

注意到其实每只股票都有以下价格特征：
| 名称 | 类型 | 描述 |
| --- | --- | --- |
| open | float | 开盘价 |
| high | float | 最高价 |
| low | float | 最低价 |
| close | float | 收盘价 |

设想：**完全不需要简单根据开盘价进行交易，而是针对每只股票都预测一个次日价格区间 [low,high]**。
假设t时刻，我们预测了t+1时刻的价格区间[L,H]。如果t+1时刻的实际价格P满足 L <= P <= H, 则预测正确。
如果次日的预测价格区间与实际价格区间有交集，那么就可以执行买入/卖出策略。
* 若按照预测，该股票需要买入，那么买入成交价是**预测区间和实际区间的交集的下界**。
* 若按照预测需要卖出，那么卖出成交价是**预测区间和实际区间的交集的上界**。
